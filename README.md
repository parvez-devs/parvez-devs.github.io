# xionhub.me Portfolio

TypeScript-powered portfolio for Muhammad Parvez / Parvez Devs.

## Structure

- `src/main.ts` — typed portfolio data, UI rendering, cinematic interactions
- `src/styles.css` — farming/gameboard visual system
- `assets/main.js` — browser-ready JavaScript compiled from the TypeScript source
- `index.html` — production entry point
- `CNAME` — custom domain: xionhub.me

## Build

```bash
npm install
npm run build
```

The visual identity stays gameboard/farming-inspired while TypeScript handles content rendering, parallax, reveal animations, section state, tilt interactions and contact flows.
